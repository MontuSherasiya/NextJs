# 🎵 Music School Website

A modern and responsive Music School Website built with **Next.js**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. This project showcases music courses, testimonials, and interactive UI components with smooth animations and a professional design.

---

## 🚀 Features

* 🎨 Modern and Responsive UI
* 🌙 Dark Mode Support
* 🎵 Music Course Showcase
* ⭐ Student Testimonials
* ⚡ Fast Performance with Next.js
* 🎭 Smooth Animations using Framer Motion
* 📱 Mobile-Friendly Design
* 🧩 Reusable Components Architecture

---

## 🛠️ Tech Stack

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/MontuSherasiya/NextJs.git
```

### Navigate to Project

```bash
cd NextJs
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
